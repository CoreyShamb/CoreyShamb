### ⚙️ Operra

**Multi-Tenant SaaS & Developer Infrastructure Platform**

A multi-service software platform designed around organizations, authentication, API access, usage tracking, billing, background processing, and cloud-hosted infrastructure.

The project is separated into multiple engineering components:

- **Operra API** — TypeScript/Node.js backend with PostgreSQL, Prisma, Redis, and cloud infrastructure
- **Operra Web** — Next.js frontend with authentication and protected application dashboards
- **Operra SDK** — TypeScript SDK for application integration
- **Operra Infrastructure** — infrastructure and production deployment configuration

**Technologies:** TypeScript · Node.js · Next.js · PostgreSQL · Prisma · Redis · Azure · Docker

[API](https://github.com/CoreyShamb/operra-api) · [Web](https://github.com/CoreyShamb/operra-web) · [SDK](https://github.com/CoreyShamb/operra-sdk) · [Infrastructure](https://github.com/CoreyShamb/operra-infra)
